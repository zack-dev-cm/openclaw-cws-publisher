# Cleanup

## Weekly Sweep Checklist

- Remove generated `dist/` reports unless explicitly kept as examples.
- Refresh docs when helper behavior changes.
- Re-scan public files for secrets, local paths, local endpoints, and dashboard dumps.
- Replace product-specific examples with generic placeholders.
- Keep Chrome Web Store dashboard operation out of the public ClawHub skill.

## Promote A Rule When

- The same release blocker appears twice.
- Review feedback repeats around listing drift, host permissions, or leak reports.
- A helper emits data that could become public without review.
